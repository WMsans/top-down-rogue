## 第二幕：做出了什么？ [0:30 - 0:50]

## 制作说明

### 团队/设备需求
- **单人拍摄**——所有素材均为屏幕录制的游戏画面。无相机、无灯光、无场地。
- **屏幕录制软件：** OBS Studio 或同类软件。以原生分辨率录制，钩子/奇观镜头尽量隐藏 UI。场景 2.2 中武器/Modifier 镜头保留 UI 可见。
- **麦克风：** 可用的 USB 或 XLR 麦克风用于配音录制。在安静的房间录制配音。
- **剪辑软件：** 任意支持多视频/音频轨道和文字叠加的非线性编辑软件（DaVinci Resolve、Premiere、CapCut 等）。

## 通读笔记

1. **场景 1.1 旁白密度：** 10 秒内 3 行（约 3.3 秒/行）。以自然的中文语速来说很舒适——每行约 12-15 字。没有拗口词。

2. **场景 1.2 流畅度：** 加速的列举结构（"火焰点燃燃气，水浇灭火，油把火烧得更猛——"）应作为一个不间断的句子来念，而非三个独立陈述。这能反映它所描述的视觉连锁反应。

3. **第二→三幕过渡：** 视频中最长的单次停顿（"核心循环已经跑通了"之后约 1.5-2 秒静默）。此停顿是有意为之——让视觉对比（战斗 → 占位素材）在配音语气转换前沉淀下来。不要匆忙跳过。

4. **场景 3.1 情感高潮：** "你画的东西，就是这个游戏最终的样子。"是对主要受众（美术）最重要的一句。如果有什么台词需要多加揣摩，就是这一句。

5. **场景 3.2 角色列表节奏：** 每个角色约 3 秒配音——紧凑但可实现。列表结构意味着配音应像"这是开放的岗位"而非"这是需要满足的要求"。结尾句"随时来随时走，参与多久都行"至关重要——它传达了低门槛。

6. **配音总字数：** 约 170 汉字用于约 75 秒的旁白。约 2.3 字/秒，是自然而不赶的节奏。

7. **无旁白时段：** 钩子（0:00-0:10）无配音。CTA（1:25-1:30）无配音。这些静默段落为旁白提供呼吸空间，让视听体验有喘息。
